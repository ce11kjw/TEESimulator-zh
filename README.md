# TEESimulator WebUI 中文翻译版

基于 [JingMatrix/TEESimulator](https://github.com/JingMatrix/TEESimulator) 的 WebUI 中文翻译。

## 说明

本仓库仅翻译了 `module/webroot` 目录中的用户界面文本，所有代码逻辑、变量名、CSS类名等均保持不变。

## 翻译内容

- 导航栏标签（配置、密钥盒、密钥、系统、日志）
- 所有按钮文本（添加、保存、删除、重命名等）
- 表单标签和提示信息
- 错误消息和确认对话框
- 系统状态文本（运行中、不可达等）
- 日志筛选和保存界面
- 密钥盒导入和检查界面
- 配置编辑器中的所有字段标签
- 作用域选择器中的筛选和排序选项
- 更新界面文本

## 使用方法

将 `webroot` 目录替换 TEESimulator 模块中的同名目录即可。

## 许可证

与原项目相同。
